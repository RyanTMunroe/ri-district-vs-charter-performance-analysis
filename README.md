# Rhode Island District vs. Charter School Performance Analysis

## Project Overview

This project analyzes Rhode Island public school performance data to compare traditional district schools and charter schools across a variety of academic performance indicators. The analysis was completed during my internship as a Curriculum Consultant to support evidence-based discussions regarding school performance and to provide clear, data-driven insights for education stakeholders.

Rather than relying on anecdotal claims, this project uses exploratory data analysis and visualizations to examine how school performance varies between district and charter schools while highlighting the range of outcomes within each group.

---

## Project Objectives

The primary objectives of this analysis were to:

* Compare academic performance between traditional district schools and charter schools.
* Summarize statewide trends across multiple performance indicators.
* Identify whether charter schools consistently outperform district schools.
* Create clear visualizations suitable for communicating findings to policymakers and education leaders.
* Produce a reproducible workflow for future analyses.

---

## Dataset ---EDIT AFTER---

The analysis uses publicly available Rhode Island school performance data.

The dataset contains school-level performance indicators, including measures related to academic achievement and school performance. Variables include school type along with multiple educational outcome metrics used throughout the analysis.

*Note: Any confidential or restricted data has been excluded from this repository.*

---

## Methodology

The project follows a standard exploratory data analysis (EDA) workflow.

### Data Preparation

* Imported and cleaned raw datasets
* Checked for missing or inconsistent values
* Standardized variable names and formats
* Prepared datasets for analysis

### Exploratory Data Analysis

* Generated descriptive statistics
* Compared distributions across school types
* Examined variation within each group
* Identified notable trends and outliers

### Data Visualization

Visualizations were created to communicate findings effectively and included:

* Bar charts
* Boxplots
* Histograms
* Distribution plots
* Comparative summary graphics

## Disclaimer

This project is intended as an exploratory analysis. It does not establish causal relationships between school type and academic performance. School outcomes are influenced by numerous factors—including demographics, funding, enrollment policies, and community characteristics—that are outside the scope of this analysis.
